Rolling a Ticket: When a roll is initiated, a random process is used to select a ticket number within the range of 1 to 1,000,000 (or any other specified range). This random process usually involves combining various factors such as server seed, client seed, and random strings obtained from external sources like random.org. These factors are hashed together to generate a unique ticket number.

Cryptographic hashing algorithms like SHA-256 are chosen for their properties of irreversibility and unpredictability. This means that given the hash value, it should be computationally infeasible to determine the original input data. As a result, the ticket number generation process is secure and resistant to manipulation or prediction.

"Provably fair" is a term used to describe a system in which the outcome of an event can be verified by both parties involved. It's often used in online gambling to ensure fairness, but it can also be applied in other areas such as blockchain transactions, voting systems, and random selection processes. The key idea is to create a transparent and trustworthy environment.
